### What I learned

<!-- Use this section to recap over some of your major learnings while working through this project. Writing these out and providing code samples of areas you want to highlight is a great way to reinforce your own knowledge. -->
- I did not think I will have to use nested grid layout so early in my web development career. But this challenge changed my thought (or fear) of using nested grid layout. Also, it gave me confidence to build complex structure using grid layout, and also using nested grid layout.
- I did not know that a little bit of change in the padding on an element can have such a great impact on the responsiveness, especially of mobile devices with small screen sizes. Also, I thought that the single media query rule for screen sizes of (max-width:640px) that I use (I use it now-a-days to match the design with the provided design at the page option in the website of devchallenges.io, the link of which is given below) for mobile devices was enough to cover the responsiveness of all mobile devices. But this thinking changed when I was trying to utilize the same media query rule for mobile devices with screen sizes around 412px (to match my site's design with the provided design for mobile phones in the design folder). As a result of which, even though the padding, font-size which I used at my site seemed to fit for mobile devices with screen sizes of 640px, I had to decrease those in order to make my site responsive for mobile devices with screen sizes of 412px. Likewise, I had to change the font-size from 4rem to 2rem for mobile devices, and to 3rem for tablet devices to avoid breaking the layout of my site.
